# Portfolio Web | David - Desarrollador Web & Móvil

Link: https://david-space.github.io/Portafolio-David/

Un sitio web de portafolio personal moderno, responsivo y dinámico diseñado para mostrar mis servicios, habilidades técnicas y proyectos destacados en el área de desarrollo web y móvil.

---

## 🚀 Características Principales

* **Sección Hero:** Presentación personal interactiva con llamado a la acción (CTA) para contacto y descarga de CV.
* **Mis Servicios:** Desglose visual de servicios de Desarrollo Web, Aplicaciones Móviles y Diseño UI/UX.
* **Sobre Mí:** Perfil profesional enfocado en el desarrollo móvil y la ingeniería de software.
* **Habilidades Tecnológicas:** Grid de tecnologías y herramientas que utilizo (Figma, Dart, Flutter, CSS3, HTML5, JavaScript, WordPress, GitHub).
* **Portafolio de Proyectos:** Galería interactiva con enlaces directos a proyectos destacados (Renova 360, Portafolio Web, Sitio de Recetas).
* **Formulario de Contacto Directo:** Sección de contacto con validación de campos para la interacción con visitantes.
* **Diseño Responsivo:** Adaptación fluida para dispositivos móviles, tablets y pantallas de escritorio mediante navegación tipo hamburguesa y divisores decorativos tipo ola en SVG.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructuración semántica del contenido.
* **CSS3:** Estilos personalizados, gradientes, efectos hover, layouts en Flexbox y Grid, e integraciones con SVG.
* **JavaScript (VanillaJS):** Lógica del menú navegacional, animaciones de interfaz y control de eventos.
